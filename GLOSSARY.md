# Breaks during agent-assisted work

A person supervising coding agents can take a break while the agents continue their work.

## Language

**Supervision load**

The demand on the person's attention from the number of active agent sessions, their duration, and especially how often the person must reply. Four agents quietly running tests can demand less attention than one agent asking repeated questions.

**Break invitation**

An offer to take a break based on the person's recent work with coding agents. The person decides whether to accept it.

**Answer delegation**

An arrangement the person accepts for a break in which a delegate answers new questions about how ongoing work should proceed in participating sessions. The set of participating sessions is fixed when the person accepts.

_Avoid “task handoff” for this arrangement._

**Held question**

A question awaiting the person's own answer on return, including a question already on screen when the break began or a new question with insufficient or conflicting evidence. Other sessions can continue in the meantime.

**Execution approval**

The person's permission to carry out a specific operation, such as deploying a change to production. During a delegated break, this request waits for the person to return.

**Human answer**

A reply the person entered or an option they selected in response to an agent's question.

**Decision preference**

A choice the person tends to make in similar situations, as evidenced by their human answers. One example is usually choosing to fix a newly discovered, unrelated bug in the current pull request.
